Rectiles and Rectigons

Rectiles

A rectile is a rectangular tile with two line segments called spokes drawn from the center to one of the rectangle vertices or midpoints of the sides. A rectile always has two spokes, but the two spokes may comprise a single line segment. Assuming that rotatons of a rectile count as the same rectile, there are 16 different rectiles. The figure to the right shows them tiling a 4x4 rectangular region inside a blue frame.

Rectile Paths

We are interested in the figures formed by the spokes of an arrangements of rectiles in the 4x4 frame so that any two tiles. Any subset of the 16 tiles may be used but adjacent tiles must border each other on a full edge or at a vertex. A path from point A to point B is a sequence of spokes such that A is only on the first spoke and B is only on the last spoke and any point on a spoke in the path is on exactly one or two spokes. We can measure the length of the path in three ways: (1) by the numbrr of tiles in the path, (2) by the number of edges, i.e. straight segments, in the path, or (2) assuming the tiles are 3 units wide and 4 units tall, by computing the length in units, which is relatively easy since the tile's diagonal will be 5 units.

In the figure to the right, the six rectiles inside the frame contain a path with "legnths" 6 tiles, 8 edges, and 25.5 units.

Many questions come to mind about paths. Here are a few:

  • What is the longest path?
  • Given two points A and B and what is the shortest path from point A to B?
  • Given two points A and B and a number n, is there a path of length n (pick one of the three measures of length) from point A to B?

Rectigons

A rectigon is a sequence of spokes such that any endpoint of a spoke in the rectigon is on exactly two spokes, and there is a path between any two spoke endpoints. The figure formed by the rectigon is a polygon. Like with the edges of a path, the sides of a rectigon are the sides of the polygon, which may consist of from one to four spokea.

The figure to the right shows a tiling that includes threee rectigons, one a triangle, one a quadrilateral, and one a pentagon.

Some questions about rectigons to investigate include:

  • For what values of n do there exist rectigon with n sides?
  • What rectigons can have a non-trivial symmetry?
  • For a rectigon with n sides, what is the minimum and maximum area? (Note that we can measure relative area easily by counting the octants, right triangles whose vertices are the center of the tile and an adjacent vertex and side midpoint of the tile.)

The Laboratory

The rectiles laboratory provides a board and a set of rectiles with which to experiment and to explore paths and rectigons. It is very simple to use: drag to move tiles and single click on a tile to rotate it 180o. The Undo button or keyboard Ctrl-Z/Command-Z undoes the last action you took. An example of the laboratory web page is shown to the right.

Underneath the tiling area, the laboratory displays a code for the tiling that can be used to recreate the tiling. If the "In frame only" checkbox is checked, the code only includes the positions of the tiles inside the blue frame. To have the code include the positions of all tiles including those outside the frame, uncheck the "In frame only" checkbox.

Copying the code makes it easy to save the tiling for future viewing. To load a tiling into the laboratory, click the "Load" button and enter the code. Alternatively, add the code to the laboratory URL as a query string with key "code".

The laboratory screen also identifies rectigons and paths and displays them with colored edges and provides the basic information about the rectigons.
